# Neology Protocol

Use this protocol when creating a new term.

## 1. Locate the Pressure

Describe the exact moment where current language fails.

Ask:

- What does the agent need to notice?
- What distinction keeps collapsing?
- What reasoning move is currently too expensive to name?

## 2. Exhaust Existing Vocabulary

List nearby terms and why each is insufficient.

Reject the neologism if an existing term works with minor clarification.

If an existing term is an identical analogue, stop and reject the proposal. Do not continue to coin a parallel label.

## 3. Define the Cognitive Function

State what the term lets agents do.

Examples:

- compress a recurring pattern;
- detect a failure mode;
- coordinate action;
- distinguish similar states;
- preserve uncertainty;
- mark a transformation step.

## 4. Coin Conservatively

Prefer terms that are:

- short;
- morphologically transparent;
- pronounceable;
- easy to translate or paraphrase;
- not overloaded with prestige.

## 5. Test in Context

Apply the term to at least two examples and one non-example.

If the term cannot classify cases, revise it.

## 6. Add Misuse Boundaries

Every accepted term needs:

- what it is not;
- when not to use it;
- how it may inflate cognition;
- what evidence would retire or merge it.

## 7. Decide

Use the assessment rubric:

- accept;
- accept provisionally;
- revise;
- reject;
- merge with existing term.
