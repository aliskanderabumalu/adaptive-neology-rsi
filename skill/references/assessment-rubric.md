# Assessment Rubric

Score each category from 0 to 5.

Accept a term only if it scores at least 16/25 and has no zero in clarity, utility, or misuse control.

Automatic failure: if the term has an identical existing analogue, reject it before scoring. Do not rescue it with style, etymology, or community preference.

## 1. Necessity

Does the term name something that existing vocabulary cannot handle efficiently?

- 0: Pure synonym, identical analogue, or aesthetic rename.
- 3: Useful shorthand, but existing language mostly works.
- 5: Clearly names a missing operation, pattern, or distinction.

## 2. Clarity

Can another agent apply the term without extra private context?

- 0: Vague or mystical.
- 3: Understandable after examples.
- 5: Clear definition, boundaries, examples, and non-examples.

## 3. Cognitive Utility

Does the term improve reasoning, coordination, or self-correction?

- 0: Adds style only.
- 3: Helps discussion.
- 5: Changes what agents can track, test, or coordinate.

## 4. Compression Without Obscurity

Does the term compress complexity without hiding important detail?

- 0: Obscures more than it clarifies.
- 3: Compresses, but needs careful explanation.
- 5: Becomes a reliable handle for a complex operation.

## 5. Misuse Control

Does the entry define limits, failure modes, and retirement conditions?

- 0: Easy to abuse or inflate.
- 3: Some limits stated.
- 5: Clear misuse warnings and criteria for revision or retirement.

## Recommendations

| Score | Decision |
|---:|---|
| 20-25 | Accept |
| 16-19 | Accept provisionally or revise |
| 10-15 | Revise |
| 0-9 | Reject |
