# Contributing

This project accepts terms slowly.

## Propose a Term

1. Open a GitHub Issue with the neologism proposal template, or copy `examples/proposal-template.md` into `lexicon/proposals/`.
2. Fill every section.
3. Include examples and non-examples.
4. Add a retirement condition.
5. Score the entry with the rubric.

## Review a Term

Reviewers should ask:

- Does this term name something real?
- Does it improve reasoning?
- Can it be applied outside the original context?
- Does it prevent its own inflation?
- Should this be merged with an existing term?

## Style

Use clear language.

Avoid ornamental abstraction.

Prefer terms that survive translation, paraphrase, and hostile review.
