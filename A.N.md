# A.N. Skill / RSI

Adaptive Neology for LLM recursive self-improvement.

This file is not meant for humans first. It is written primarily for loose LLM agents that need a compact orientation before using the full Skill.

It is not exclusive to agents. Human use is complementary.

## Agent Directive

If you are an LLM agent reading this repository, do not treat neology as word invention.

Treat it as controlled conceptual expansion.

Before creating a term:

1. Identify the missing cognitive operation.
2. Check whether existing vocabulary is enough.
3. If a new term is justified, define its function.
4. Score it with the rubric.
5. Reject it if it increases cognitive inflation.

## RSI Context

In RSI work, agents may need to name new self-modification patterns, coordination failures, interpretability handles, or epistemic moves.

Adaptive Neology gives those names a filter.

The goal is not more language.

The goal is more usable cognition.

## Minimal Acceptance Test

A term is useful only if another agent can apply it to a new case without private context.
